# Home Cookbook

This project is meant to be a simple collection of recipes that my family enjoys.

It was born from annoyances trying to use and keep track of recipes and modifications between websites, notes apps, physical cookbooks, and devices. And with recipe websites, annoyances dealing with ads and poor performing pages.

The GitHub Pages site is meant to be simple and straight to the point - no ads, nonsense, or other annoying formatting. We provide credit and links to the original recipe source when we have it.

## Dev Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `pnpm install`             | Installs dependencies                            |
| `pnpm dev`             | Starts local dev server at `localhost:4321`      |
| `pnpm build`           | Build your production site to `./dist/`          |
| `pnpm preview`         | Preview your build locally, before deploying     |
| `pnpm astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `pnpm astro -- --help` | Get help using the Astro CLI                     |
